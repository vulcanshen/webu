由 analysis 從 README 整理（2026-11-09），不是使用者的原話。

webu 是終端機裡的瀏覽器，把網頁當一份文件來讀：抓下這一頁，只顯示它直接給的內容（文章、文件、答案），導覽列、側欄、頁尾、cookie 告示都不顯示，想看時可以切到整頁。

給在終端機裡工作、想用鍵盤讀網頁的人：像 `less` 一樣捲動、找字，在能按的東西（連結、圖片、欄位、按鈕）之間走，跟著連結走、上一頁下一頁。

要輕：不下載、不執行瀏覽器，一頁就是一個請求。不跑網頁的 JavaScript。

表單做到不需要 JavaScript 的程度：搜尋框、簡單的帳密登入；登入後一直有效。

瀏覽器該有的都要有：分頁（每個分頁前面是網站的記號，顏色取自它的 favicon）、有目錄的書籤（能從任何瀏覽器匯入）、歷史、下載；看這一頁的原始碼、這個網站的 cookie、載入它發出的請求；選字複製到剪貼簿、整頁輸出成 markdown。

設定可以在 app 裡改，也可以手改 YAML；搬到新位置的檔第一次啟動時搬過去；自己的檔讀不了時，先問要不要搬開再開始。

平台：macOS（Intel 與 Apple Silicon）與 Linux（amd64 與 arm64），沒有 Windows 版。用 Homebrew 或安裝腳本裝。

不能發生的事：
- 不跑網頁的 JavaScript，也不自己跑一個瀏覽器。
- 不支援滑鼠，只用鍵盤。
- 打進欄位的值（可能是密碼）不記下來；登入狀態只有使用者自己讀得到。
- 刪設定與資料之前一定先問。

限制（README 寫的）：靠 script 才長出內容的網頁看到的很少；圖片、影片、音訊只有 icon 與網址；CAPTCHA、passkey、需要 JavaScript 或別的網站帳號的登入都不行。
